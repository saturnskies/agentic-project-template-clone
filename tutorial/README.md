# Setup Tutorial

Everything you need to go from a fresh computer to a working Claude Code project built on these best practices. Follow the steps in order; each one ends with a quick check.

| Step | Guide | Time |
|------|-------|------|
| 1 | [Set up your computer](01-computer-setup.md) — Git, Node.js, Python, browser, terminal, Lightpanda | 20–40 min |
| 2 | [Install Claude Code](02-install-claude-code.md) — install, sign in, verify | 10 min |

## What you're setting up

- **Claude Code** — Anthropic's coding agent that runs in your terminal ([official docs](https://code.claude.com/docs/en/overview))
- **This project template** — a `.claude/` setup with a workflow plugin (Superpowers), agents, skills, hooks, and MCP servers already configured
- **Your machine** — the tools Claude Code drives while it works: Git, Node.js, Python, a browser

## What you need before starting

- A computer running **Windows 10 (1809+) / Windows 11, macOS 13+, or Ubuntu 20.04+** with 4 GB+ RAM (16 GB+ recommended)
- A **paid Claude plan** — Pro, Max, Team, or Enterprise (the free plan doesn't include Claude Code). Max gives much more room for subagents and long-running loops
- A **GitHub account** — free is fine
- About an hour
